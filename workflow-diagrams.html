หมายเหตุประจำผัง

  • ต้องตัดสินใจ
    ลบผู้ใช้แล้ว งานที่เขาถืออยู่จะ cascade หรือ set null? ต้องตัดสินใจก่อนเขียน migration แรก ไม่ใช่ตอนเจอ error ตอน demo
  • กฎ
    เปลี่ยน role แล้ว JWT เดิมยังฝัง role เก่าไว้ — เลือกทางใดทางหนึ่ง: บังคับ logout หรืออ่าน role จาก DB ทุก request แทนที่จะเชื่อ payload ใน token
  • กฎ
    ADMIN ลบคอมเมนต์ของใครก็ได้ (DELETE /comments/:id) ส่วน role อื่นลบได้เฉพาะของตัวเอง
  • กฎ
    ลบเอกสารต้องลบไฟล์บน Cloudinary ด้วย ไม่ใช่ลบแค่แถวใน DB แล้วปล่อยไฟล์ค้าง
